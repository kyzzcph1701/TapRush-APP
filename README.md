# TapRush Android

Native Android Kotlin version of TapRush.

- 100% offline at runtime
- No WebView
- No internet permission
- CPS, combo, challenges and local high score
- Minimum Android 6.0 (API 23)
- Compile/target SDK 35
- Kotlin + AndroidX

Open the project in Android Studio and build with **Build > Build APK(s)**.

Debug APK:
`app/build/outputs/apk/debug/app-debug.apk`

Package:
`com.kyzzcph1701.taprush`
